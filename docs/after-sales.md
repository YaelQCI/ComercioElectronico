# Solicitudes posventa (#28)

`/solicitudes` permite consultar y solicitar devoluciones o Price Match por unidades del pedido. La cuenta propietaria o una credencial vigente del pedido autoriza acceso; correo y número público nunca bastan. Evidencia mediante enlaces HTTPS: no se descargan ni se generan guías de Envia.com.

API comprador: POST `/api/after-sales`, `action: list|request`, `orderId`, credencial opcional `guestToken`. Para solicitar: UUID `idempotencyKey`, `type: RETURN|PRICE_MATCH`, `unitIds`, descripción y evidencia `[{url,description}]`. RETURN incluye motivo y condición; PRICE_MATCH comparación `[{unitId,itemCents,shippingCents}]` en centavos de texto.

API administrativa: POST `/api/admin/claims/:id`, `type`, `action: inspect|review|receive|resolve`. Revisión requiere `decision: APPROVE|REJECT`, motivo; devolución además `storeFault` explícito, Price Match aprobado exige `sameVariant: true` e `includesMexicoShipping: true`. Inspección devuelve identificadores de artículos para recepción: `inspections: [{itemId,condition,disposition,notes}]`. Recepción registra stock y reserva reintegros; no liquida dinero. Procesar `refundId` con el endpoint administrativo de pagos existente. Resolver exige reintegros SETTLED; sin reintegro requiere `noRefundDecision: true` y motivo auditado.

Plazos calculados con reloj PostgreSQL: siete días desde confirmación para Price Match; treinta desde entrega para devolución. Pedidos bloqueados serializan aprobaciones, cancelaciones y reservas de reintegro. Restitución al lote original solo sellado, aprobado vendible, lote vigente y no bloqueado; demás entradas no vendibles. El envío original se reintegra una sola vez al completar devolución total con responsabilidad de tienda. Reparto dinero/puntos respeta asignaciones originales y reintegros pendientes; la liquidación existente restaura canjes y revierte puntos ganados.

Pendientes: interfaz administrativa completa y logística manual de retorno/costo documentado; validación de combo parcial y múltiples lotes, reintegros mixtos y carreras con cancelación; pruebas Stripe sandbox y navegador; aprobación de políticas comerciales antes de habilitación pública. La credencial de invitado actual caduca a siete días: renovar mediante prueba de control verificada requiere el proveedor de correo pendiente, necesario para acceso durante todo el plazo de treinta días. No usar datos públicos como sustituto.
